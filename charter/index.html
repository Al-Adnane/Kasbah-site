Kasbah Charter

  1. User control is absolute. No silent actions.
  2. No silent data exfiltration. Local-first by default.
  3. Security claims must be provable. No fake badges.
  4. Clarity over complexity. Explain decisions in plain language.
  5. No dark patterns. Respect consent and reversibility.
This charter is short on purpose. If it needs a paragraph, it’s probably not a principle.
