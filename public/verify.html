Verify your download

This page exists for one reason: to make downloads feel safe and verifiable.

macOS DMG (recommended)

1) Download the DMG and checksum file:

Download DMG   Download SHA256

2) Verify checksum:

cd ~/Downloads
shasum -a 256 KasbahGuard-macOS.dmg
cat KasbahGuard-macOS.dmg.sha256

3) Verify macOS Gatekeeper status (after download):

spctl -a -vv -t install KasbahGuard-macOS.dmg || true

Chrome extension ZIP (developer preview)

Download ZIP   Download SHA256 

cd ~/Downloads
shasum -a 256 kasbah-guard-extension-v0.3.0.zip
cat kasbah-guard-extension-v0.3.0.zip.sha256

Then load unpacked in Chrome: chrome://extensions → Developer mode → Load unpacked.

What Kasbah does (plain language)

Kasbah stops accidental leaks before they leave your laptop: copied secrets, pasted keys, uploaded files, and risky prompts.

It runs locally. You can test it with the demo, and verify the binaries with checksums above.
