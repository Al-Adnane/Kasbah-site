Privacy Policy — Kasbah Guard

Last updated:

Kasbah Guard is a browser extension designed to help users prevent accidental sharing of sensitive information with AI-powered websites.

Information We Do Not Collect

Kasbah Guard does not collect, transmit, sell, or share:

  • Personal data
  • Sensitive information (such as passwords, credit card numbers, or IDs)
  • Browsing history
  • Page content
  • Keystrokes
  • Clipboard contents
  • Files or file contents

All detection and blocking logic runs locally in the user's browser.

Information Stored Locally

Kasbah Guard stores limited data locally on the user's device using browser storage:

  • Extension settings (enabled/disabled state, sensitivity preferences)
  • Local audit metadata (allow/deny decisions)

This data does not leave the user's device.

Permissions

Kasbah Guard requests access to specific AI websites only to intercept user-initiated actions (such as paste, send, or file upload) and display a blocking or approval interface before data is submitted. Access is limited to supported AI domains and is not used for tracking or analytics.

Network Access

Kasbah Guard does not transmit user data to external servers. The extension does not perform analytics, advertising, or user profiling.

Remote Code

Kasbah Guard does not download or execute remote code. All executable logic is bundled with the extension distributed through the Chrome Web Store.

Third Parties

Kasbah Guard does not share data with third parties and does not integrate third-party tracking, analytics, or advertising services.
