🔐 Install Kasbah Guard for Safari

Protect your secrets before they reach ChatGPT, Claude, or any AI tool.

Download Extension
1
Download the extension from GitHub releases (click button above)
2
Open Safari → Develop menu
If you don't see "Develop" in the menu bar:
Safari → Settings → Advanced → Enable "Show Develop menu in menu bar"
3
Click Develop → Allow Unsigned Extensions
4
Go to Safari → Settings → Extensions
Click the + button and select the downloaded extension folder
5
Grant Permissions
When prompted, allow access to "All websites" so Kasbah Guard can protect you everywhere
⚠️ Note: Safari extensions on macOS require developer signing for distribution. We're working on Mac App Store approval. Until then, you can load this unsigned extension locally.
