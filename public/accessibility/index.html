♿ Accessibility

Kasbah Guard is built for everyone. Four notification modes, nine languages, WCAG 2.1 AA compliance, and full support for seven disability types. Security tools must be accessible to all developers.

Four Notification Modes

📝

Text Notifications

Clear, concise alerts in your browser language. Auto-detects from your settings, or choose from 9 languages: English, Spanish, French, German, Japanese, Chinese, Portuguese, Russian, Arabic.

  • Auto-detects your browser language
  • Manual override in settings
  • Works across all 5 browsers
  • 100% local, zero external calls
🎤

Voice Feedback

Natural speech synthesis announces detections in your language using the Web Speech API. Hear alerts without looking at the screen.

  • Web Speech API (browser native)
  • 9 languages with native voices
  • Customizable speed and pitch
  • Works offline, no AI required
🔔

Audio Alerts

Quick tones tell you what's happening without words. 5 alert types at different frequencies (400–1000 Hz) using the Web Audio API.

  • Low Risk: 600 Hz single beep
  • Medium Risk: 750 Hz double beep
  • High Risk: 1000 Hz triple beep
  • Success: 800 Hz rising tone
  • Error: 400 Hz falling tone
⌨️

Keyboard Navigation

Complete keyboard control of all features. No mouse needed. Zero keyboard traps, focus always visible.

  • ? — Show help & shortcuts
  • Alt+D — Toggle detection
  • Alt+R — Redact selection
  • Alt+V — Toggle voice
  • Esc — Close popup

System Preference Detection

🌙

Dark Mode

Automatically switches to dark colors if your OS is in dark mode. Works on Windows, Mac, Linux, iOS, Android.

⬆️

High Contrast

Increases border thickness and color contrast if your OS has high contrast mode enabled. Essential for low vision users.

⏸️

Reduced Motion

Respects prefers-reduced-motion system setting. All animations disabled for users who need it, preventing motion sickness.

WCAG 2.1 Level AA Compliance

We meet 14+ criteria from the Web Content Accessibility Guidelines:

  • 1.1.1 Non-text Content: All icons have text labels
  • 1.3.1 Info & Relationships: Semantic HTML structure
  • 1.4.3 Contrast Minimum: 4.5:1 text, 3:1 UI elements
  • 2.1.1 Keyboard: All features fully keyboard accessible
  • 2.1.2 No Keyboard Trap: Can escape all elements
  • 2.4.3 Focus Order: Logical left-to-right navigation
  • 2.4.7 Focus Visible: 3px bright outline always visible
  • 2.5.4 Motion Actuation: Respects prefers-reduced-motion
  • 3.3.2 Labels: All inputs properly labeled
  • 4.1.2 Name, Role, Value: All components have ARIA
  • 4.1.3 Status Messages: ARIA live regions announce changes

Getting Started

Your extension is already updated

If you installed Kasbah Guard recently, you already have all accessibility features. Open the extension popup and look for the ♿ Accessibility section.

To enable accessibility features:

  1. Click the Kasbah Guard extension icon (top-right)
  2. Scroll to ♿ Accessibility section
  3. Enable features:
    • 🌐 Language — Choose your language or auto-detect
    • 📢 Screen Reader — Enabled by default
    • 🔔 Audio Alerts — Enabled by default
    • 🎤 Voice Feedback — Optional, disabled by default
  4. Your settings save automatically

Privacy First

All accessibility features respect your privacy:

  • Local Processing: Audio synthesis and text-to-speech happen on your device only
  • No External Calls: Zero API requests for accessibility
  • No Tracking: We don't track which features you use
  • Browser Native: Uses only standard Web Audio API and Web Speech API
