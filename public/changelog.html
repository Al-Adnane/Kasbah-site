Changelog

What shipped and when. No hype — only what's live.

v2.0.0 February 23, 2026 Enterprise Edition
  • UEBA Engine — User & Entity Behavior Analytics with z-score anomaly detection, EMA risk scoring, 8 behavior metrics, per-user data movement tracking
  • Extended PII Detection (100+ types) — GitHub PAT, Slack/Discord/Telegram tokens, GCP keys, NPM/PyPI tokens, Stripe/SendGrid/Twilio keys, database URLs, Vault tokens, ICD-10 codes, health insurance IDs, high-entropy secrets
  • Multi-Model Ensemble — Pattern (0.4) + Entropy (0.3) + Semantic (0.3) weighted confidence scoring
  • Compliance Engine — GDPR, HIPAA, PCI-DSS, SOC 2, ISO 27001 templates with violation detection and remediation guidance
  • RBAC + Fleet Management — 5 roles (Admin, Security Analyst, Compliance Officer, Team Lead, Viewer), device registry, permission enforcement
  • Process Monitor — AI process detection (15+ tools), network egress scanning, suspicious port flagging
  • Shannon Entropy Detection — High-entropy secret identification using information theory
  • Semantic PII Detection — Context-aware medical, financial, identity, biometric, and credential detection
  • File Edit Notifications — Interactive Review/Allow dialogs for flagged files, brief notifications for clean file edits by AI agents
  • Desktop App Enterprise Pages — Compliance framework manager, UEBA risk dashboard, Process Monitor with live scanning
  • 18 self-tests (up from 12), 65+ HTTP endpoints, 5,275+ audit chain entries INTACT
  • Full capability report with methodology and reproducible test commands
v1.5.0 February 21, 2026
  • 3-layer session persistence — Tauri IPC + localStorage + HTTP fallback. Sessions survive cache clears via macOS Keychain + file backup
  • OS-level authority — Clipboard monitor (30ms ultra-fast polling), filesystem watcher, keystroke volume tracking
  • Cryptographic audit chain — HMAC-SHA256 hash-chained ledger with signed exports
  • TF-IDF ML classifier — Logistic regression for injection, credential leak, PII leak, code exfiltration
  • Desktop app redesign — New sidebar, protection banner, activity feed, authority page, system check
  • 12 self-tests, ticket-based decisions, kill switch, velocity tracking, replay protection
v1.0.0 February 20, 2026
  • Demo simulator with 4 scenarios (credentials, API key, file edit, personal data)
  • Download verification with checksums
  • macOS desktop engine running on 127.0.0.1:8788
  • Browser extensions (Chrome, Edge, Firefox, Safari) — developer preview
  • Website launch at bekasbah.com
