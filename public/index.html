How it works

Four steps. Thirty seconds.

1
DetectKasbah sees what the AI is attempting — send, paste, upload, download, browse, and edit your files. Six verbs intercepted at the gate.
2
Bind"Who is in charge of this session?" You are. Authority is claimed locally on your device via HMAC‑signed tickets.
3
EnforceEvery action checked against your delegation. Secrets detected, risk scored, unauthorized actions blocked at the wall.
4
ReclaimOne click freezes all agentic processes. Authority reclaimed. Hash‑chained audit trail preserved. The fortress holds.
Security architecture

13-MOAT Defense Model

Every layer is a moat around your data. Thirteen independent defenses — each one a wall an attacker must breach. Real security is depth.

Input Control
M1 6-verb gate — send, paste, upload, download, browse, edit
M9 Clipboard audit — real-time data channel monitoring
M10 Default-DENY — fail-closed, nothing passes unchecked
Data Analysis
M2 PII detection — SSN, credit card, IBAN, passport
M3 Secret scanning — API keys, private keys, JWTs
M4 ML classification — TF-IDF with 4-class detection
M5 Prompt injection defense — pattern + ML detection
Cryptographic
M6 HMAC-SHA256 tickets — cryptographic authority proof
M7 Replay protection — single-use, SQLite-persisted
M8 Hash-chained audit — tamper-evident logging
M12 Signed export — HMAC-verified audit bundles
Operational
M11 Kill switch — instant authority reclaim
M13 Posture enforcement — firewall, encryption, updates
