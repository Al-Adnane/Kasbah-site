Six ways your secrets escape without Kasbah

Send

Emailing a password by mistake

You forward a thread thinking it's internal. An API key or password is buried in the thread. It reaches an external inbox in seconds.

Paste

Pasting secrets into ChatGPT

You copy a config file or customer list, paste it into ChatGPT for analysis. Your data is now in their training pipeline. Forever.

Upload

Uploading identity documents

You upload a passport.jpg, ID.pdf, or tax_return.pdf to a cloud service. The filename alone identifies what's inside before anyone opens it.

Edit

Typing card numbers into forms

You type a credit card into a checkout form. Browser scripts cache it. A third-party tracker logs it. Kasbah warns you in real time.

Browse

URLs with personal data

You navigate to a link with your email or SSN as a URL parameter. It leaks to the server logs, browser history, and any proxy watching.

Download

Files that reveal what's inside

You download customer_data.csv, employee_ssns.xlsx. The filename tells anyone watching exactly what you're pulling. Kasbah logs it.
