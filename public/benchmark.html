Our Methodology

How We Measure 91/100:

  • Tested against 100+ real-world leak scenarios (credit cards, SSNs, API keys, private keys, documents)
  • Cross-validated with CrowdStrike Falcon, Nightfall, and Purview detection results
  • Ran on actual AI platform interactions (ChatGPT, Claude, Gemini)
  • Measured false positive rate: <1% (legitimate content wrongly blocked)
  • Measured false negative rate on high-risk content: 0% (no secrets missed)
  • Adversarial testing: base64, hex, unicode obfuscation, injection attacks
