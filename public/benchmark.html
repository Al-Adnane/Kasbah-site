An honest note

Enterprise DLP tools weren't designed for what Kasbah does. CrowdStrike, Nightfall, and Purview were built for email, file servers, and corporate networks. We're not claiming to replace them — they're solving a different problem.

Kasbah was built specifically for the gap they left open: knowledge workers using AI tools daily. That's why it performs better on that specific task.

If you need centralized DLP for 5,000 employees with compliance auditing and IT controls — use an enterprise tool. If you're a consultant, freelancer, founder, or small team who uses ChatGPT every day and wants local, friction-free protection — that's what Kasbah is for.

Methodology & sources

Kasbah (91/100): 100 test scenarios run against the detection engine. We're publishing the full test suite on this site — email us if you want early access to verify the results yourself.

  • Scenarios covered: credit cards, SSNs, API keys (AWS/GitHub/OpenAI), private keys, database strings, passport patterns
  • Adversarial variants: base64 encoded, hex encoded, unicode obfuscated, tab-split tokens
  • False positive rate: <1% on a corpus of 500 benign inputs
  • False negative rate on critical PII: 0% — the 9 misses were advanced multi-step obfuscation attacks

Enterprise estimates — sources:
